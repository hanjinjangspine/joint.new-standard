# 전페이지 이미지 디자인 v1

기존 병원 자산: 본원 navigation-card-backgrounds-v2의 20개 설명용 배경 이미지. 해당 기존 자산의 의미를 유지하며 카드 제목을 우선해 연결한다. 생성·연출 이미지는 실제 환자·의료진·시설 사진으로 설명하지 않는다.

새 garden-v1.webp: 2026-10-05 imagegen으로 생성한 추상 식물 그림자·유리 질감의 장식 배경. 인물·장비·진료 장면·문자·로고 없음. 장식 배경이므로 대체텍스트를 새로 붙이거나 의료정보로 노출하지 않는다. 실제 병원 사진과 의료진 사진은 보존한다.

각 공개 페이지의 공통 레이아웃에서 적용. 글 박스의 주제를 우선 매핑하고, 기존 사진이 있는 카드·예약 버튼·메뉴·서식·어두운 CTA는 보존한다. 모바일의 이미지 명암을 줄이고 인쇄에서는 배경을 생략한다.
